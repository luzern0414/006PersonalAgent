# 01 · 业务理解与功能需求（PRD）

> 项目代号：**PersonalAgent（桌面小管家）**
> 版本：v0.1 草案 · 2026-10-10

---

## 1. 业务理解

### 1.1 一句话定位

一个**常驻 Windows 桌面的个人工作 Agent**：平时是一只安静的小宠物（或一个迷你悬浮球），需要时展开为信息面板；它了解你的**日程、任务、待办和知识**，会在合适的时间**主动提醒**，也能听懂自然语言帮你**记录、查询、汇总、发送**。

### 1.2 用户画像

- 每天固定在 Windows 电脑前工作的知识工作者（开发 / 产品 / 运营 / 职能）。
- 工作信息分散在：IM（企业微信 / 钉钉 / 飞书）、邮件、日历、各种文档、自己的笔记。
- 痛点：
  1. **信息碎片化**：今天要做什么、几点开会，要切好几个软件才能看全。
  2. **容易忘**：临时答应的事、下班前要发的日报、喝水久坐。
  3. **知识沉淀难**：好文档、踩坑记录散落各处，用时找不到。
  4. **重复劳动**：每天写日报 / 周报、同步日程给同事。
  5. 现有 AI 工具是"被动的"：必须打开网页、切换窗口才能用。

### 1.3 核心价值

| 价值 | 说明 |
|---|---|
| 一眼可见 | 桌面角落常驻，天气、下一个会议、今日任务数一眼可见，不用切窗口 |
| 主动而不打扰 | 到点提醒、下班提醒、会议前提醒，但全屏 / 演示 / 会议中自动静默 |
| 随手沉淀 | 拖一个文件、粘一段文字、说一句"记一下"，就进入知识库 / 待办 |
| 会干活 | 自然语言驱动：生成日报、把今天日程发到群里、从知识库里找答案 |
| 本地优先 | 数据存在本机 `data/`，可离线使用，隐私可控 |
| 可扩展 | 插件化：新增一个数据源或一个工具，不需要改核心 |

### 1.4 一天的使用旅程（核心场景）

```
08:50 开机  → 小宠物醒来伸懒腰，气泡：「早上好！今天 23℃ 多云，有 3 个会议、5 项任务，昨天还有 2 项没完成」
            → 点击展开「今日面板」：天气卡 / 今日日程时间轴 / 今日任务 / 待办
09:30 工作中 → Alt+Space 唤起输入框：「下午三点前把接口文档发给小王」→ 自动生成待办 + 15:00 前提醒
10:55 会前   → 宠物举牌：「11:00 需求评审，会议室 A」（全屏演示时改为托盘通知）
14:00 沉淀   → 把一份 PDF 拖到宠物身上 → 宠物"吃掉"文件 → 解析入库，气泡：「已收进知识库：《XX 接口规范》，共 42 段」
14:20 查询   → 「我们的接口鉴权是怎么规定的？」→ 基于知识库回答并附出处
17:30 下班前 → 宠物提醒：「还有 30 分钟下班，今天完成 4/5 项，要我生成日报吗？」
            → 一键生成日报 → 预览/修改 → 确认后发送到飞书群 / 邮件
18:00 下班   → 「下班啦！」宠物换成睡觉动画；未完成任务自动顺延到明天（可配置）
```

## 2. 产品形态

产品有 **4 种形态**，可自由切换：

| 形态 | 描述 | 尺寸（参考） | 触发 |
|---|---|---|---|
| **宠物态**（默认） | 透明背景的小角色，有待机/走动/睡觉/思考/说话/提醒等动画，头顶可冒气泡 | 约 160×160 | 默认 |
| **悬浮球态** | 极简圆形小球，显示下一事件倒计时 / 未完成数徽章，适合不想要角色的用户 | 约 56×56 | 设置切换 |
| **面板态** | 单击宠物展开的卡片式面板：今日概览、对话、待办、知识库、设置 | 约 400×640 | 单击宠物 / 快捷键 |
| **隐藏态** | 只在系统托盘，提醒走系统通知 | — | 双击托盘 / 快捷键切换 |

### 2.1 通用交互规则

- **拖动**：按住宠物任意拖动；松手后自动**吸附屏幕边缘**；靠边可"半藏"（只露半个头）。
- **位置记忆**：记住每台显示器上的位置，多显示器 / DPI 缩放正确。
- **点击穿透**：宠物透明区域鼠标穿透，不挡住下面的窗口。
- **始终置顶**：可配置；检测到全屏应用（游戏、PPT 放映、视频）时自动隐藏或降级。
- **不抢焦点**：气泡与提醒不抢键盘焦点，不打断正在输入的内容。
- **右键菜单**：快速记待办、打开面板、勿扰 1 小时、切换形态、设置、退出。
- **拖拽上传**：任何文件 / 文件夹 / 文本 / 网页链接拖到宠物或面板上 → 弹出"放到哪"小菜单（知识库 / 附件到某任务 / 让 AI 总结）。
- **全局快捷键**：
  - `Alt+Space`：唤起快速输入（类似 Spotlight）
  - `Alt+Shift+P`：展开/收起面板
  - `Alt+Shift+T`：快速新建待办
  - `Alt+Shift+H`：隐藏/显示宠物

## 3. 功能需求清单

优先级：**P0** = MVP 必须；**P1** = 第二阶段；**P2** = 远期。

### F1 桌面悬浮与宠物（P0）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F1.1 | 透明、无边框、置顶、不显示任务栏图标的宠物窗口 | P0 | 桌面上只看到角色本身，无窗口边框 |
| F1.2 | 拖动 + 边缘吸附 + 位置记忆 | P0 | 重启后位置恢复；多显示器正确 |
| F1.3 | 透明区域点击穿透 | P0 | 宠物旁边的桌面图标可正常点击 |
| F1.4 | 宠物状态机动画：idle / walk / sleep / think / talk / alert / happy / drag | P0 | 不同业务事件触发对应动画 |
| F1.5 | 气泡消息（支持富文本、按钮：好的 / 稍后 / 不再提醒） | P0 | 气泡 N 秒后自动消失，可点击展开 |
| F1.6 | 宠物皮肤包（帧动画 / Lottie / 可选 Live2D），可替换 | P1 | 放入 `assets/pets/<name>/` 即可切换 |
| F1.7 | 悬浮球态 | P1 | |
| F1.8 | 全屏 / 演示 / 游戏检测自动静默 | P0 | PPT 放映时不弹气泡 |
| F1.9 | 闲置检测（长时间无键鼠输入宠物去睡觉，回来打招呼） | P1 | |
| F1.10 | 宠物"养成"小互动（摸头、喂食=完成任务奖励） | P2 | 增加趣味与完成任务的正反馈 |

### F2 Agent 对话（P0）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F2.1 | 面板内对话 + 快速输入框，流式输出 | P0 | 首字 < 2s（云模型） |
| F2.2 | 多模型：Claude / OpenAI 兼容接口（DeepSeek、通义、Kimi 等）/ 本地 Ollama | P0 | 设置里可切换，配置在 `config/llm.yaml` |
| F2.3 | 工具调用：Agent 可调用待办、日程、天气、知识库、提醒、发送消息等工具 | P0 | 说"明天上午十点提醒我交报销" → 生成提醒 |
| F2.4 | 外发类动作（发消息、发邮件、删除）必须**用户确认** | P0 | 发送前展示预览卡片 |
| F2.5 | 会话历史、多会话 | P0 | |
| F2.6 | 长期记忆：记住用户偏好（称呼、下班时间、常用群） | P1 | 可在设置中查看/删除记忆 |
| F2.7 | MCP 客户端：接入任意 MCP Server 扩展工具 | P1 | `config/mcp.yaml` 配置即可加载 |
| F2.8 | 语音输入（按住说话）/ TTS 播报 | P2 | |
| F2.9 | 截图提问（框选屏幕区域发给 AI） | P2 | |

### F3 天气（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| F3.1 | 当前天气 + 今日温度区间 + 未来 3 天，显示在面板天气卡 | P0 |
| F3.2 | 城市自动定位（IP）或手动设置 | P0 |
| F3.3 | 恶劣天气 / 下雨提醒（上班前 / 下班前提示带伞） | P1 |
| F3.4 | 宠物外观随天气变化（下雨打伞） | P2 |

数据源：默认 **Open-Meteo**（免费、无需 Key），国内可选 **和风天气 QWeather**（更准、需 Key）。

### F4 提醒（P0）

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| F4.1 | **下班提醒** | P0 | 根据 `config/app.yaml` 工作时间；下班前 N 分钟预提醒 + 准点提醒；可附带"今日完成情况" |
| F4.2 | 自定义提醒（一次性 / 重复 / cron） | P0 | 自然语言创建："每周五下午四点提醒我写周报" |
| F4.3 | 会议前提醒（日程开始前 N 分钟） | P0 | |
| F4.4 | 健康提醒：喝水、久坐、护眼 | P1 | 基于实际键鼠活跃时长而不是死板定时 |
| F4.5 | 稍后提醒（snooze 5/10/30 分钟） | P0 | |
| F4.6 | 节假日 / 调休感知（中国法定节假日） | P1 | 节假日不发下班提醒 |
| F4.7 | 提醒渠道：宠物气泡 → Windows 系统通知 → 手机（推送到 IM） | P1 | 逐级降级 |

### F5 工作日程（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| F5.1 | 本地日程增删改查，今日时间轴视图 | P0 |
| F5.2 | 订阅外部日历：ICS 链接（通用）、Outlook / Microsoft 365（Graph API）、飞书 / 钉钉日历 | P1 |
| F5.3 | **发送工作日程**：把今日 / 本周日程生成文本或卡片，发送到指定 IM 群 / 个人 / 邮件 | P0 |
| F5.4 | 自然语言建日程："周三下午两点到三点和产品对需求" | P0 |
| F5.5 | 冲突检测与空闲时段推荐 | P2 |

### F6 今日任务与待办（P0）

> 区分：**任务（Task）** = 有项目归属、有截止时间、需要进度的工作项；**待办（Todo）** = 轻量随手事项。底层统一为 `tasks` 表，用 `kind` 区分，界面分两个 Tab。

| 编号 | 需求 | 优先级 |
|---|---|---|
| F6.1 | 今日任务列表：今天截止 / 今天计划做 / 逾期 | P0 |
| F6.2 | 待办快速添加（快捷键、自然语言、拖拽文本） | P0 |
| F6.3 | 优先级、标签、项目、截止时间、子任务 | P0 |
| F6.4 | 完成打勾（宠物给予正反馈动画） | P0 |
| F6.5 | 未完成自动顺延 / 次日早报提醒 | P1 |
| F6.6 | 外部同步：Microsoft To Do / 飞书任务 / Jira / GitLab Issue（插件） | P2 |
| F6.7 | 从聊天 / 文件中自动提取待办（AI 识别 "请你周五前…"） | P1 |

### F7 消息发送（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| F7.1 | 渠道：企业微信群机器人 / 钉钉群机器人 / 飞书群机器人（Webhook） | P0 |
| F7.2 | 渠道：邮件（SMTP） | P1 |
| F7.3 | 渠道：Windows 系统通知（给自己） | P0 |
| F7.4 | 消息模板（日报、日程、自定义），支持 Markdown / 卡片 | P0 |
| F7.5 | 定时发送（如每天 17:50 自动生成日报草稿，确认后发送） | P1 |
| F7.6 | 发送记录与失败重试 | P1 |

> 说明：个人微信 / QQ 无官方开放接口，**不做**（避免封号与合规风险）。

### F8 知识库沉淀（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| F8.1 | **拖拽上传**：文件（PDF / Word / Excel / PPT / Markdown / TXT / 图片 / 代码）、文件夹、网页链接、纯文本 | P0 |
| F8.2 | 自动解析 → 分块 → 向量化 → 入库，进度在面板显示 | P0 |
| F8.3 | 知识问答：回答附带引用出处（文件名 + 段落），可点击打开原文 | P0 |
| F8.4 | 随手记（Markdown 笔记），保存在 `data/notes/`，同样可被检索 | P0 |
| F8.5 | 知识分类：空间 / 标签；AI 自动打标签与生成摘要 | P1 |
| F8.6 | 监听文件夹自动入库（如 `data/knowledge/inbox` 或指定的工作目录） | P1 |
| F8.7 | 图片 OCR、扫描件 PDF 识别 | P1 |
| F8.8 | 知识卡片复习 / 每周知识回顾 | P2 |

### F9 日报 / 周报（P1，MVP 可先做日报）

- 素材：今日完成任务、会议、新增知识、对话中记录的工作事项。
- 输出：按 `config/prompts/daily_report.md` 模板生成，可编辑后发送（走 F7）。
- 周报 = 聚合本周日报。

### F10 今日面板（Dashboard，P0）

面板首页卡片（可排序、可隐藏）：
1. 问候 + 日期 + 距下班倒计时
2. 天气卡
3. 今日日程时间轴（当前时间线高亮）
4. 今日任务（进度条 x/y）
5. 待办
6. 最近知识 / 随手记
7. 快速输入框（底部常驻）

### F11 插件系统（P1）

- 一个插件 = 一组 **Tools**（给 Agent 用）+ 可选 **Panel 卡片**（给 UI 用）+ 可选 **Trigger**（定时 / 事件）。
- 首批内置插件：weather、calendar、tasks、reminder、knowledge、messenger、report。
- 第三方：放入 `plugins/` 目录；同时支持 MCP Server 作为外部插件。

### F12 设置与系统（P0）

- 开机自启、单实例、托盘、自动更新（P1）。
- 配置可视化编辑，与 `config/*.yaml` 双向同步。
- 数据备份 / 导出（`data/backups/`），一键导出 Markdown / JSON。
- 密钥安全：API Key 存 Windows 凭据管理器，不写明文。

## 4. 非功能需求

| 类别 | 指标 |
|---|---|
| 资源占用 | 空闲内存 ≤ 200 MB（含 Python 后台），CPU 空闲 < 1%；宠物动画 ≤ 30fps 且失焦降帧 |
| 启动 | 冷启动到宠物出现 ≤ 3s |
| 稳定性 | 后台服务崩溃自动拉起；提醒任务持久化，重启不丢 |
| 隐私 | 数据默认全部本地；调用云端模型时可配置"敏感词脱敏"；知识库可选本地 Embedding |
| 离线 | 无网络时：待办、提醒、日程、本地检索全部可用；对话可降级为本地模型 |
| 兼容 | Windows 10 21H2+ / Windows 11；100%–200% DPI；多显示器 |
| 可维护 | 配置与代码分离；插件热加载；日志在 `data/logs/` 按天滚动 |

## 5. 不做 / 暂不做

- 个人微信、QQ 自动化（无官方接口，风险高）。
- 移动端 App（以 IM 推送代替）。
- 多人协作 / 团队知识库（个人工具定位）。
- 全自动电脑操控（Computer Use）——放到远期调研。

## 6. MVP 范围（第一版要交付的）

- 宠物态 + 面板态，拖动、吸附、穿透、托盘、快捷键
- 对话（Claude / OpenAI 兼容 / Ollama）+ 工具调用
- 天气卡、今日日程（本地）、今日任务与待办
- 下班提醒、自定义提醒、会前提醒
- 拖拽上传入知识库 + 带出处问答 + 随手记
- 飞书 / 企业微信 / 钉钉 Webhook 发送日程与日报（发送前确认）
