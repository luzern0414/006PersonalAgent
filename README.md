# PersonalAgent · 桌面小管家

一个常驻在 Windows 桌面上的个人工作 Agent：平时是一只叫「团子」的小猫，点它就打开或收起一个固定在桌面上的信息面板。

- 🐱 **桌宠**：透明置顶，透明区域点击穿透；可以拖动并贴边吸附；眼睛跟着鼠标转，离开电脑会睡觉，下雨天撑伞，专注时戴耳机
- 🗓 **今日**：天气（深圳，渐变天空 + 逐小时预报）→ 安排 → 知识库，一页滚动看完；上班时看今天，快下班或下班后自动切到明天
- 📋 **日程待办**：月历加当天安排（日程、提醒、待办按时间排在一起），完成的划线保留；还能看接下来 30 天
- ⏰ **提醒**：喝水、起立、护眼（频率可调，按实际用电脑的时长计时），下班预告、上班早报、会前提醒、任务到期提醒、自定义重复提醒；全屏、安静时段和专注时自动免打扰
- 💬 **Agent 对话**：待办、提醒、日程的新增和修改都在对话里完成；一个连续的对话，可以查看全部历史；24 个工具，能用一句话完成新建任务、日程、提醒，检索知识库，写日报并发送；删除和外发前会弹确认卡
- 📚 **知识库**：把文件拖到团子身上就能入库（PDF / Word / Excel / PPT / 图片 / Markdown / 网页 / 代码），**图片、扫描件和截图会自动 OCR**，回答会标注出处；还能写随手记
- 📤 **发送**：日程和日报可以发到飞书、企业微信、钉钉群
- 🔗 **LangSmith**：每轮对话的完整 `chain → llm → tool` 链路都会被追踪
- ⚡ **不卡顿**：业务逻辑运行在独立后台进程，联网、解析大文件、调用模型都不会让宠物和面板卡住；常驻内存约 250MB（含诊断用的运行监测进程）

## 快速开始

1. 在 `config/apikey.txt` 中写入模型网关的地址、Key 和 LangSmith Key（格式见 `config/apikey.example.txt`）；也可以在「设置 → AI 服务」里直接填写地址和 Key
2. 双击 **`启动小管家.cmd`**（首次运行会自动 `npm install`）
3. 右下角出现团子后，点它打开面板。设置都是改完自动保存（当前为 `gpt-6-luna`）

## 目录

```
apps/desktop/      桌面端源码（Electron；core/ 为不依赖 Electron 的业务核心）
config/            settings.json（首次运行时生成）、apikey.txt、prompts/
data/              运行时数据（位置可在设置中修改）
docs/              需求、调研、设计与实现文档
启动小管家.cmd      一键启动
```
