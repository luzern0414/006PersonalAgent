# 05 · 开发路线图与风险

## 1. 里程碑

| 阶段 | 目标 | 主要内容 | 预估 |
|---|---|---|---|
| **M0 原型验证** | 证明窗口技术可行 | Tauri 透明置顶宠物窗口、拖动吸附、点击穿透、托盘、全局快捷键；Python sidecar 拉起与鉴权通信；拖入文件拿到路径 | 1 周 |
| **M1 MVP** | 能日常用起来 | 面板（今日概览/对话/待办/设置）；LLM Gateway（Claude + OpenAI 兼容 + Ollama）+ Tool Loop；任务/待办 CRUD；本地日程；天气；下班/自定义/会前提醒；气泡 + 系统通知 | 3 周 |
| **M2 知识库** | 沉淀与问答 | 拖拽入库流水线、混合检索、带出处问答、随手记、inbox 监听 | 2 周 |
| **M3 外联** | 会发、会汇报 | 飞书/企微/钉钉 Webhook、SMTP；发送日程；日报/周报生成；发送确认与 outbox | 1.5 周 |
| **M4 体验打磨** | 好看、好玩、稳定 | 宠物皮肤包规范与 2 套皮肤；全屏/闲置/锁屏感知；节假日；长期记忆；安装包、自启、自动更新 | 2 周 |
| **M5 扩展** | 平台化 | 插件规范落地；MCP 客户端 + MCP Server；ICS/Outlook/飞书日历；Jira/GitLab 插件 | 持续 |
| **远期** | | 语音对话、截图提问、上下文感知、Live2D、手机端推送互动 | — |

## 2. M0 验证清单（先做最有风险的）

- [ ] 透明窗口在 Win10 / Win11、100%/150%/200% DPI 下无黑边、无闪烁
- [ ] 透明像素点击穿透 + 不透明像素可拖动
- [ ] 多显示器拖动与位置恢复
- [ ] 全屏应用（PPT 放映）检测
- [ ] Python sidecar 打包后体积与冷启动时间（目标 < 2s 可服务）
- [ ] 空闲内存总占用（目标 ≤ 200MB）
- [ ] 拖拽文件到透明窗口能收到 `drop` 事件

## 3. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 透明窗口穿透在 WebView2 下实现复杂 | 体验核心 | M0 优先验证；参考 BongoCat；兜底方案：宠物窗口做成刚好包住角色的小矩形，不做逐像素穿透 |
| Python sidecar 打包体积大（Docling/OCR 依赖重） | 安装包 > 300MB | 重型依赖做成"按需下载组件"；MVP 只带 MarkItDown |
| 主动提醒过多引起反感 | 用户关掉 | 频控 + 免打扰 + "不再提醒"一键学习；所有主动行为可在设置中逐项关闭 |
| 云端模型隐私 | 企业数据外泄 | 本地模型选项、脱敏规则、"仅本地"知识空间 |
| 企业 IM 只能群机器人，无法发给个人 | 发送场景受限 | 先做群机器人；后续接入企业自建应用（需企业管理员授权） |
| LLM 自然语言时间解析错误 | 提醒时间错 | 解析结果以卡片回显，用户可一键修改；常见表达用规则引擎（如 `dateparser`）兜底 |
| 杀毒软件 / SmartScreen 误报 | 安装受阻 | 代码签名；sidecar 不使用 UPX 压缩 |

## 4. 目录结构约定

```
006PersonalAgent/
├── apps/desktop/        # Tauri 2 + React 前端与 Rust 壳（src/、src-tauri/）
├── services/agent/      # Python 后台服务（FastAPI sidecar）
├── plugins/             # 第三方/自定义插件
├── assets/pets/         # 宠物皮肤包
├── config/              # 配置（yaml + prompts），可提交（不含密钥）
├── data/                # 运行时数据（不提交 git）
└── docs/                # 文档
```
