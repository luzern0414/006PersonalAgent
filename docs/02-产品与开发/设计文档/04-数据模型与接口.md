# 04 · 数据模型与接口设计

> ⚠️ 本文是设计阶段的数据模型。v0.1 实际使用 JSON 文件存储，接口为 Electron IPC，详见 [06-实现说明](../%E5%BC%80%E5%8F%91%E8%AE%B0%E5%BD%95/06-%E5%AE%9E%E7%8E%B0%E8%AF%B4%E6%98%8E.md)。

## 1. 数据目录（`data/`）

```
data/
├── db/
│   ├── agent.db            # SQLite 主库（业务数据 + FTS5 全文索引）
│   ├── scheduler.db        # APScheduler 任务持久化
│   └── vectors/            # LanceDB 向量库
├── knowledge/
│   ├── inbox/              # 监听目录：丢进来的文件自动入库
│   └── library/            # 解析后的 Markdown 副本（便于人读、可迁移）
├── uploads/YYYY/MM/        # 拖拽上传的原始文件副本（按 sha256 去重）
├── notes/                  # 随手记，Markdown 文件，文件即数据源
├── cache/                  # 天气、日历订阅、模型等缓存，可随时删除
├── logs/                   # 按天滚动日志
└── backups/                # 定期备份（db + notes 打包 zip）
```

原则：**Markdown 文件是一等公民**——笔记和解析后的知识都以 Markdown 存在磁盘上，即使程序没了，数据也能直接用。

## 2. SQLite 表结构（核心）

```sql
-- 任务与待办（kind 区分）
CREATE TABLE tasks (
  id            TEXT PRIMARY KEY,          -- ULID
  kind          TEXT NOT NULL DEFAULT 'todo',  -- 'task' | 'todo'
  title         TEXT NOT NULL,
  notes         TEXT,
  status        TEXT NOT NULL DEFAULT 'open',  -- open | doing | done | cancelled
  priority      INTEGER DEFAULT 2,         -- 0 紧急 1 高 2 中 3 低
  project       TEXT,
  tags          TEXT,                      -- JSON 数组
  plan_date     DATE,                      -- 计划哪天做（"今日任务"的依据）
  due_at        DATETIME,
  completed_at  DATETIME,
  parent_id     TEXT REFERENCES tasks(id), -- 子任务
  source        TEXT DEFAULT 'manual',     -- manual | chat | kb | jira | ...
  external_id   TEXT,                      -- 外部同步 ID
  created_at    DATETIME NOT NULL,
  updated_at    DATETIME NOT NULL
);

-- 日程（本地 + 外部订阅缓存）
CREATE TABLE events (
  id            TEXT PRIMARY KEY,
  title         TEXT NOT NULL,
  location      TEXT,
  description   TEXT,
  start_at      DATETIME NOT NULL,
  end_at        DATETIME NOT NULL,
  all_day       INTEGER DEFAULT 0,
  rrule         TEXT,                      -- 重复规则 RFC 5545
  remind_before INTEGER DEFAULT 10,        -- 提前提醒分钟数
  calendar_id   TEXT NOT NULL DEFAULT 'local',
  external_id   TEXT,
  created_at    DATETIME, updated_at DATETIME
);

CREATE TABLE calendars (
  id TEXT PRIMARY KEY, name TEXT, type TEXT,  -- local | ics | graph | feishu
  url TEXT, color TEXT, enabled INTEGER DEFAULT 1, last_sync_at DATETIME
);

-- 提醒
CREATE TABLE reminders (
  id            TEXT PRIMARY KEY,
  text          TEXT NOT NULL,
  trigger_type  TEXT NOT NULL,             -- once | cron | event_before | workday_offwork
  trigger_value TEXT NOT NULL,             -- ISO 时间 / cron 表达式 / 事件ID
  workday_only  INTEGER DEFAULT 0,
  related_type  TEXT, related_id TEXT,     -- 关联任务/日程
  channels      TEXT DEFAULT '["bubble","toast"]',
  enabled       INTEGER DEFAULT 1,
  snooze_until  DATETIME,
  last_fired_at DATETIME,
  created_at    DATETIME
);

-- 知识库
CREATE TABLE kb_spaces (
  id TEXT PRIMARY KEY, name TEXT, local_only INTEGER DEFAULT 0, created_at DATETIME
);
CREATE TABLE documents (
  id TEXT PRIMARY KEY, space_id TEXT REFERENCES kb_spaces(id),
  title TEXT, source_type TEXT,            -- file | url | text | note
  source_path TEXT, stored_path TEXT, md_path TEXT,
  mime TEXT, size INTEGER, sha256 TEXT UNIQUE,
  summary TEXT, tags TEXT,
  status TEXT,                             -- pending | parsing | embedding | ready | failed
  error TEXT, chunk_count INTEGER, created_at DATETIME, updated_at DATETIME
);
CREATE TABLE chunks (
  id TEXT PRIMARY KEY, doc_id TEXT REFERENCES documents(id) ON DELETE CASCADE,
  seq INTEGER, heading_path TEXT, page INTEGER, content TEXT, token_count INTEGER
);
CREATE VIRTUAL TABLE chunks_fts USING fts5(content, heading_path, content='chunks', content_rowid='rowid', tokenize='trigram');

-- 随手记（索引，正文在 data/notes/*.md）
CREATE TABLE notes (
  id TEXT PRIMARY KEY, title TEXT, path TEXT, tags TEXT, doc_id TEXT, created_at DATETIME, updated_at DATETIME
);

-- 对话
CREATE TABLE conversations (id TEXT PRIMARY KEY, title TEXT, model TEXT, created_at DATETIME, updated_at DATETIME);
CREATE TABLE messages (
  id TEXT PRIMARY KEY, conversation_id TEXT REFERENCES conversations(id) ON DELETE CASCADE,
  role TEXT,                               -- user | assistant | tool
  content TEXT, tool_calls TEXT, citations TEXT, tokens_in INTEGER, tokens_out INTEGER, created_at DATETIME
);

-- 长期记忆（用户画像事实）
CREATE TABLE memories (
  id TEXT PRIMARY KEY, fact TEXT, category TEXT, source_msg_id TEXT, confidence REAL, created_at DATETIME, updated_at DATETIME
);

-- 消息渠道与发送记录
CREATE TABLE channels (
  id TEXT PRIMARY KEY, name TEXT, type TEXT,  -- feishu | wecom | dingtalk | email | toast
  config TEXT,                                -- JSON，密钥只存 secret:// 引用
  enabled INTEGER DEFAULT 1
);
CREATE TABLE outbox (
  id TEXT PRIMARY KEY, channel_id TEXT, title TEXT, content TEXT, format TEXT,
  status TEXT,                                -- draft | confirmed | sent | failed
  error TEXT, retry INTEGER DEFAULT 0, scheduled_at DATETIME, sent_at DATETIME, created_at DATETIME
);

-- 日报
CREATE TABLE reports (
  id TEXT PRIMARY KEY, kind TEXT, period_start DATE, period_end DATE, content TEXT, outbox_id TEXT, created_at DATETIME
);
```

## 3. REST API（后台 Python，前缀 `/api`）

所有请求头：`Authorization: Bearer <token>`。

| 模块 | 方法 & 路径 | 说明 |
|---|---|---|
| 系统 | `GET /health` | 健康检查 |
| | `GET /today` | **今日快照**：问候、天气、日程、任务统计、距下班时间（面板首页一次拿全） |
| 对话 | `POST /chat`（SSE） | body: `{conversation_id?, message, attachments?}`；流式事件：`delta` / `tool_call` / `confirm_required` / `citation` / `done` |
| | `POST /chat/confirm` | `{confirm_id, approved, edited_args?}` 对需确认的工具调用作答 |
| | `GET/DELETE /conversations[/{id}]` | 会话管理 |
| 任务 | `GET /tasks?view=today\|todo\|overdue\|all&kind=` | 列表 |
| | `POST /tasks` · `PATCH /tasks/{id}` · `DELETE /tasks/{id}` | CRUD |
| | `POST /tasks/parse` | 自然语言 → 结构化任务（快速输入用） |
| 日程 | `GET /events?from=&to=` · `POST/PATCH/DELETE /events[/{id}]` | |
| | `POST /calendars/{id}/sync` | 手动同步外部日历 |
| | `POST /events/share` | `{range: today\|week, channel_id}` 生成并发送日程（返回草稿，需确认） |
| 提醒 | `GET/POST/PATCH/DELETE /reminders[/{id}]` | |
| | `POST /reminders/{id}/snooze` | `{minutes}` |
| 天气 | `GET /weather?city=` | 带缓存 |
| 知识库 | `POST /kb/ingest` | `{paths?: [], urls?: [], text?: "", space_id}` → 返回 job 列表 |
| | `GET /kb/documents` · `DELETE /kb/documents/{id}` · `POST /kb/documents/{id}/reindex` | |
| | `POST /kb/search` | `{query, top_k, space_id?}` 返回片段 + 出处 |
| 笔记 | `GET/POST/PATCH/DELETE /notes[/{id}]` | |
| 渠道 | `GET/POST/PATCH/DELETE /channels[/{id}]` · `POST /channels/{id}/test` | |
| 发送 | `POST /outbox` · `POST /outbox/{id}/send` · `GET /outbox` | 草稿 → 确认 → 发送 |
| 报告 | `POST /reports/generate` | `{kind: daily\|weekly, date}` |
| 记忆 | `GET/DELETE /memories[/{id}]` | |
| 设置 | `GET/PUT /settings` | 读写 config（保存回 yaml） |

## 4. WebSocket 事件（`/ws/events`，后台 → 前端）

```jsonc
{ "type": "pet.state",       "data": { "state": "alert", "duration": 5000 } }
{ "type": "bubble.show",     "data": { "id": "...", "text": "11:00 需求评审", "level": "info",
                                       "actions": [{"id":"ok","label":"好的"},{"id":"snooze","label":"10 分钟后"}] } }
{ "type": "reminder.fired",  "data": { "reminder_id": "...", "text": "..." } }
{ "type": "kb.progress",     "data": { "doc_id": "...", "status": "embedding", "progress": 0.6 } }
{ "type": "task.changed",    "data": { "id": "...", "op": "update" } }
{ "type": "today.refresh",   "data": {} }
```

前端 → 后台（同一连接）：

```jsonc
{ "type": "bubble.action",   "data": { "id": "...", "action": "snooze" } }
{ "type": "system.state",    "data": { "fullscreen": true, "idle_seconds": 0, "locked": false } }
```

## 5. Tauri 命令（前端 → Rust）

| 命令 | 说明 |
|---|---|
| `get_backend_info()` | 返回 `{port, token}` |
| `toggle_panel()` / `show_quick_input()` | 窗口控制 |
| `set_pet_hit_mask(mask)` | 上报当前帧的低分辨率 alpha 掩码，用于穿透命中测试 |
| `snap_to_edge()` | 吸附 |
| `open_path(path, page?)` | 用系统默认程序打开文件（引用出处跳转） |
